## Caveats

- PRECON homes (Lahore, 2018-19) are mostly large 3-phase houses; a household near 200 units is smaller. The target is the scale-free ratio final / (rate so far x 30), which is what transfers.
- Windows overlap (30-day windows every 15 days), so rows are not independent within a house; folds are by house, so this does not leak across the train/test split.
- naive and last_ratio are point forecasts, so their coverage and Brier are those of a 0/1 call.
